# campaign-report-agent

An LLM report writer for monthly paid media reporting that **can't make up numbers**, and an eval suite that proves it.

```
campaign CSV ──► kpis.py ──► KPI JSON (raw + pre-formatted display strings)
                               │
                               ▼
                         narrate.py (Claude) ──► narrative.md
                                                     │
                                  evals/grounding.py ◄┘   fails? → don't render
                                                     │
                                         render_docx.py ──► report.docx
```

> Sample data is synthetic: a fictional retailer ("Aldercrest Home") across Google Ads, Microsoft Ads, and Meta, generated by `data/generate_sample.py`.

## The problem

Ask an LLM to "write up last month's performance" from a spreadsheet and it will do arithmetic, round things its own way, and occasionally invent a number that sounds right. In a client report, one wrong CPA is worse than no report.

## The approach

1. **Deterministic KPIs.** `report_agent/kpis.py` computes every metric (spend, conversions, CPA, ROAS, CTR, CVR, MoM change) by total, platform, and campaign. Ratios are ratios of sums. ROAS is computed over ecommerce spend only, so lead-gen spend doesn't drag it down.
2. **Pre-formatted numbers.** Each block carries `display` strings (`"$53.85"`, `"+1.6%"`, `"3.53x"`). The system prompt tells the model to copy only those, verbatim, and never compute.
3. **A grounding check that gates rendering.** `evals/grounding.py` parses the narrative and checks:
   - every number matches a `display` value (same unit and precision), which catches hallucinated and self-rounded numbers
   - claims like "CPA rose" match the sign of the change, for the total or the platform named
   - all four required sections are present
   - no month is mentioned other than the reporting and comparison month
4. **The evaluator is tested too.** `tests/test_grounding.py` plants errors (a fake spend figure, a rounded CPA, a flipped direction at the total and platform level, a missing section, a wrong month) and asserts each one is caught, and that a correct narrative passes for every month.

## Run it

```bash
pip install -r requirements.txt
python -m report_agent --month 2026-08                  # offline template narrative, no API key
export ANTHROPIC_API_KEY=...
python -m report_agent --month 2026-08 --mode llm       # Claude writes the narrative
```

Outputs land in `out/`: the KPI JSON, the narrative, and the .docx. If the narrative fails grounding, the run stops before rendering and prints the issues.

## Evals

```bash
python -m evals.run_evals --mode offline                          # deterministic baseline
python -m evals.run_evals --mode llm --runs 5                     # 5 generations x 4 months
python -m evals.run_evals --mode llm --runs 5 --model <model-id>  # compare models
```

Each run writes `evals/results/<timestamp>_<mode>.json` with pass rate, mean number-grounding rate, and issue counts by type, plus every narrative for review. Use it to compare prompt versions or models before changing what goes to clients.

| Metric | What it tells you |
|---|---|
| pass rate | share of narratives that would have shipped |
| mean grounding rate | share of cited numbers that trace to the KPI JSON |
| `ungrounded_number` count | the model computing or rounding on its own |
| `wrong_direction` count | the model misreading a change (most often CPA, where down is good) |

### Known limits

- Plain integers 1–12 and years aren't checked, to avoid flagging list counts and dates.
- Direction is only judged when a sentence names exactly one metric and one direction; ambiguous sentences are skipped rather than guessed at. That trades recall for zero false positives in the gate.

## Use as a Claude skill

`SKILL.md` packages the same workflow for Claude (Claude Code or a claude.ai skill): Claude runs the KPI step, writes the narrative itself, runs the grounding check, fixes flagged sentences, and only then renders.

## Tests

```bash
pytest -q    # KPI math (ratios of sums, platform totals reconcile, ROAS scope) + evaluator recall
```
